# Reekium
Reekium is a modern graphics engine written in C++, built from the ground up utilizing OpenGL and serves as a playground in computer graphics for educational purposes.

## Prerequisites

Note: If you are on an immutable Linux distribution (like Bazzite) you will not be permitted to perform the actions in the script below.
In order to get around this you will need to run the scripts inside a container. On Bazzite, this can easily be set up like so; 
```
$ toolbox create
$ toolbox enter
```

Install required dependencies by running `$ bash install_deps.sh`

## Build & Run

- `$ bash build.sh`
- `$ ./build/Reekium`
